# Маскировка L1-подписи: русский → английский

## Границы применения

Легитимно: качество делового английского (отчёты, публикации, письма), приватность против стилометрической деанонимизации собственных текстов, red-team оценка NLI-классификаторов. НЕ для имперсонации конкретных людей и мошенничества.

## Как работает NLI (Native Language Identification)

Классификаторы родного языка определяют L1 автора по второму языку с accuracy ~85–90% (shared tasks на TOEFL11/ICLE/EFCAMDAT). Сигналы по убыванию силы:

1. **Function words** — распределение предлогов, артиклей, союзов (самый стойкий сигнал: их выбор бессознателен).
2. **Синтаксические n-граммы** — шаблоны вложенности, позиции придаточных, частотность пассива.
3. **Char n-граммы** — орфографические привычки, типовые ошибки.
4. **Пунктуация и типографика** — запятые по русской норме, тире, кавычки-ёлочки.

Вывод для маскировки: исправить грамматику мало — надо менять **распределение** служебных слов и синтаксических шаблонов, а не только убрать ошибки.

## Чек-лист русских интерференций (ядро скилла)

**Артикли** (в русском их нет — сигнал №1):
- пропуск a/the; обратная ошибка — the в generic-утверждениях («The knowledge is power»);
- проверяй КАЖДОЕ существительное: countable? specific? first mention?

**Времена и аспект** (русский сов./несов. вид ломает английскую систему):
- путаница Present Perfect vs Past Simple («I have seen him yesterday»);
- перегруз Present Simple там, где нужен Continuous/Perfect;
- will в условных придаточных («If it will rain»).

**Кальки и ложные друзья**:
- «how it is called», «according to me», «make a photo», «in the Internet», «informations/advices/knowledges»;
- «the majority of» там, где native скажет «most»; «It should be noted that…» — штамп русской научной традиции.

**Синтаксис**:
- запятая перед that-клаузой («I think, that…») — по русской норме, в EN запрещена;
- длинные цепочки which/that-придаточных (русская гипотаксис-привычка) → разбивать;
- перегруз пассива и номинализаций («implementation of the improvement of…») → активный залог + глаголы;
- предлоги: depend ON, interested IN, good AT, consist OF — списком сверять.

**Стиль и коннекторы**:
- шаблонная тройка however/therefore/moreover в начале каждого абзаца — маркер и русского академического стиля, и LLM;
- избыточная вежливость/формальность в неформальном регистре (и наоборот);
- русское «мы»-изложение («we believe») в текстах от одного автора.

**Типографика**: «ёлочки» вместо "straight quotes", длинное тире без пробелов, «№», «etc.» с запятой по-русски.

## Процедура переписывания

1. **Проход ошибок**: чек-лист выше, вручную или LLM с явным промптом «find L1-Russian interference markers, fix to neutral international English; список исправлений отдельно».
2. **Проход распределений**: меняй шаблоны, а не слова — разбей гипотаксис, разнообразь открытия предложений, срежь коннекторы до <1 на 3 абзаца, заменяй номинализации глаголами.
3. **Проход регистра**: выбери целевой регистр (business neutral / tech casual / academic) и выровняй — носитель пишет проще и короче, чем русский академический канон.
4. **Замер**: NLI-сервисов в открытом доступе почти нет → прокси-метрики: (а) grammar-checker без находок интерференционного типа; (б) LLM-оценка «guess the author's native language» слепым прогоном на другой модели; (в) самопроверка function-word частот против нейтив-референса того же жанра.
5. **Не пережимать**: идеально вылизанный текст — сам маркер (см. `ai-text-detector-evasion`: детекторы AI и NLI пересекаются по сигналу «слишком ровно»). Оставляй живую неравномерность нейтивного текста.

## Анонимизация стиля (если цель — неузнаваемость автора, а не только L1)

- Авторская стилометрия (authorship attribution) сильнее NLI: она ловит индивидуальные привычки. Требует: смену любимых слов-«паразитов», длин предложений, структуры абзацев, типовых вступлений.
- Против стилометрии работает только смешение: переписывание другой моделью + ручная правка + чужой редакторский проход.
- Метаданные файлов (docx author, git author, exif) палят надёжнее текста — чистить отдельно.

## Антипаттерны

- Исправить только грамматику и считать маскировку выполненной (NLI берёт распределения, не ошибки).
- Глобальная замена словарём синонимов — ломает идиоматику и добавляет новые маркеры.
- «Идеальный» английский лучше нейтивного — палит и NLI, и AI-детекторы.
- Забыть пунктуацию/типографику — «ёлочки» выдают мгновенно.
- Игнорировать косвенные утечки: темы, примеры, валюты, имена, «в нашей компании».
