# AI Detector Evasion Skills

Навыки (Agent Skills) по устройству и обходу детекторов AI-сгенерированного контента и стилометрической атрибуции. Три навыка в формате `SKILL.md` (YAML-frontmatter + инструкция), пригодны для любых агентных сред, поддерживающих формат навыков.

## Состав

| Навык | О чём |
|---|---|
| `skills/ai-text-detector-evasion` | Детекторы AI-текста: zero-shot статистические (perplexity/burstiness, DetectGPT, Fast-DetectGPT, Binoculars), обученные классификаторы (GPTZero, Originality.ai, Turnitin AI, Copyleaks, Winston, Pangram, ZeroGPT, Sapling), водяные знаки (KGW, SynthID). Методы обхода по эффективности: рекурсивный парафраз (DIPPER), температурные возмущения, инжекция ошибок, бёрстинес-инжиниринг, translation round-trip, humanizer-сервисы. Протокол жёсткого обхода топ-детекторов (Pangram, Turnitin). Русскоязычная специфика. **Эмпирика с тест-стенда**: замеры PPL/burstiness по стадиям протокола. |
| `skills/ai-code-detector-evasion` | Детекторы AI-кода: кодовая стилометрия (SANER 2025), perplexity/perturbation, CodeVision, watermarking токенов, коммерческие сервисы. Почему публичные детекторы кода слабые. Методы обхода: человеческие правки, рефакторинг-проходы, смена идиом, стилевая денормализация. Defender-сторона (проверка чужого кода). |
| `skills/native-language-masking` | Маскировка L1-подписи носителя русского в английском тексте: как работает NLI (Native Language Identification, ~85–90% accuracy на TOEFL11/ICLE/EFCAMDAT), чек-лист русских интерференций (артикли, аспект, кальки, пунктуация, коннекторы, номинализации), процедура переписывания под нейтральный интернациональный английский, анонимизация авторского стиля. |

## Границы применения

Материалы — для законных сценариев:

- проверка **собственных** текстов на ложные срабатывания (детекторы регулярно помечают человеческий текст как AI — задокументированная проблема, особенно на академическом стиле);
- red-team оценка надёжности детекторов;
- аудит собственного кода и текстов перед политиковыми проверками;
- исследования watermarking, стилометрии и атрибуции авторства.

Навыки **не предназначены** для академического мошенничества, дезинформации и имперсонации. Ключевая честная рамка, зафиксированная в навыках: **100%-го обхода топовых детекторов не существует** — автоматика не дотягивает до человеческого статистического профиля, единственный устойчивый метод против топ-классификаторов — реальное человеческое переписывание значительной части текста.

## Ключевые эмпирические находки (замерено на стенде, август 2026)

- Парафраз **другой** моделью — сильнейший автоматический рычаг: перплексия текста выросла ×2.5 за один проход (7.5 → 18.7).
- Каждый LLM-проход накладывает **свою** низкоперплексную сигнатуру: после проходов другой моделью PPL упал обратно до 12.2. Порядок проходов критичен.
- Автоматический протокол не дотягивает до человеческого уровня (12 vs 49 PPL, 0.55 vs 0.71 burstiness CV).
- LLM-судья бесполезен как прокси детектора: настоящий человеческий текст из arXiv оценён как «92% AI».

Воспроизведение стенда: `llama-perplexity` из llama.cpp на любой локальной GGUF-модели (`-c 256` для текстов <2048 токенов) + коэффициент вариации длин предложений (burstiness).
